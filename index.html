Per l'anteprima live serve HTTPS o localhost e il permesso della fotocamera. La foto viene inviata a Pl@ntNet solo quando premi «Analizza».

Come ottenere risultati migliori

  • Fotografa una sola pianta, ben illuminata.
  • Metti a fuoco foglie, fiori o frutti.
  • Confronta le specie suggerite prima di scegliere.
  • Non usare il riconoscimento per decidere se una pianta sia commestibile.

CONNESSIONI

Impostazioni API

Le ricerche GBIF e Wikipedia non richiedono credenziali. Per usare Pl@ntNet, ogni studente deve inserire la propria chiave API personale, salvata solo nel suo browser.

Riconoscimento Pl@ntNet

Fino a 500 identificazioni/giorno nel piano gratuito, secondo le condizioni del fornitore.

Nessuna chiave è inclusa nei file pubblicati su GitHub. Quella che inserisci viene salvata nell’IndexedDB di questo browser, non nel repository, e può essere rimossa. Ricorda che una chiave usata dal browser non è segreta rispetto al dispositivo o alle sue richieste di rete.

Autorizza il dominio per CORS

Nel portale Pl@ntNet abilita le chiamate dal browser e autorizza il dominio del sito, includendo protocollo e porta in fase di sviluppo.

DIDATTICA APERTA

Laboratorio degli studenti

Arricchisci le schede con osservazioni basate su fonti, modifica i contenuti in IndexedDB ed esporta il lavoro della classe. Le schede create qui sono contributi da verificare, non valutazioni scientifiche approvate.

Crea o modifica una scheda

I dati rimangono salvati in questo browser.

Progetto collaborativo

1. Cerca una specie o carica una scheda esistente.
2. Inserisci informazioni qualitativamente verificabili.
3. Aggiungi almeno una fonte affidabile.
4. Salva ed esporta un file JSON per condividere i contributi con la classe.

L'insegnante dovrà controllare i contributi prima di considerarli validati. Nessun contenuto degli studenti viene caricato su un server EcoFlora.

Scambia l'archivio

Esporta contributi, preferiti e cronologia; importa un archivio proveniente da un compagno. La chiave API non viene inclusa nei file esportati.

Documentazione inclusa

Apri i file della cartella docs/ per le istruzioni, la struttura del codice, gli esercizi e i test.
